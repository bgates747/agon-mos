## Production UART integration — pending human review

C-001 [x] The Author explicitly selected callback/session exclusion. Open
refuses an installed user keyboard callback; callback registration first
fences and closes the session. Native-ROM tests deliver actual keyboard
packets into MOS, execute a synchronous-printing callback and verify CONTEXT
for a new async call from it. The callback remains in the UART ISR.

C-002 [x] The Author explicitly selected retention and indefinite wait during
CTS-stalled application return. The fence retains RAM, drains the queue and
TEMT, then discards only safe terminal/reserved descriptors and closes.
Five native-ROM cases halt CTS after different amounts of progress, verify
that the fence has not returned or freed its source, then resume CTS and
verify exact completion with IFF still disabled. No automatic FIFO/parser
reset or destructive timeout is introduced. RST38 drains an intact consumer;
entry during UART service retains state for explicit reset.

TX-001 [x] Production policy review is complete with those explicit selections.
The API contract is now concrete in `docs/uart0-async.md`; the register ABI is

TX-005 [x] Implementation and automated qualification are delivered. The shared

C/assembly options, and treats linker warnings as fatal. The existing
quickrand return-path compiler warning remains visible.
