# ASY-001 — MOS asynchronous UART0 transmission

Executive summary: this owned MOS fork is the implementation owner for a
general ordered UART0 transmit facility. Preserve the existing wire protocol,
baud rate, CTS and receive parser. First deliver the concrete design for review;
then build an isolated driver and producer benchmark before game integration.
The Author authorized that isolated tranche on 2026-10-12; it is now delivered
and qualified using native ZDS II under Wine on Oryx Linux Lite.

## Provenance and scope

Transferred by the Author's handoff on 2026-10-12 from

implementation after discussing the two integration decisions. Those decisions
remain review gates for live MOS integration, not for the isolated experiment.

The baseline source is `6de0eafcb2cd328a8e33c160f7a364bd04592558`, branch
`qsort`. Isolated development uses `codex/uart0-async`, with pre-existing qsort edits in `src/mos_api.asm` and

application, network service or physical bench change is part of this design
delivery. No hardware ownership or lease is assumed.
