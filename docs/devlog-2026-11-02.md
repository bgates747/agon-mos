# 2026-11-02 — UART0 caller convenience experiment

The Author authorized developing UX-001 after explicitly choosing a mode switch:
unaware applications retain stock RST18 behavior. Aware applications may opt into
a copying queue and optional completion callbacks. The goal is simpler app code
without giving up the proven interrupt-driven sender or hiding EMOS size costs.

Implemented in src/uart0_completion.inc, with scoped changes to the MOS adapter,
driver release paths and active-session RST18 dispatch. No protected release
startup/UART/interrupt file changed. The experiment advertises a tentative
append-only ABI1.3; old offsets/ordinary open/RST18 semantics remain. This is not
upstream or EMOS API allocation and is not the active Jukebox candidate.

Convenience borrowed writes automate ticket management. Source-consumed
notifications can invoke a bounded direct callback from masked MOS service or
the UART ISR, or be taken and dispatched in foreground by a library. Direct
callbacks preserve both register banks and indexes, reject API reentry, and may
precede submission return. Do not confuse them with wire/remote completion.

Copied RST18 is a separate quiescent session opt-in; three256-byte buffers hold
owned copies. Fixed writes use LDIR, large calls apply backpressure, delimited
writes work, and nonzero-MBASE callers retain synchronous compatibility.
The direct-delivery/null-callback mode allows automatic retirement without
notification. Event-taking copied mode is rejected because retaining all three
slots as undelivered events could deadlock the same foreground RST18 caller.
Callbacks are retired before app return drains sources and restores stock state.
No new crash recovery or VDP code was added.

Actual-ROM tests caught a fixture address overlap on the65535byte case; its source
was moved away from stub/callback code. Source review additionally found the
RST18 low16-bit count convention; run005 truncates BCU before private block
copying and has a dedicated regression. Failed borrowed submissions preserve
last accepted ID, though attempted allocations may leave sequence gaps. The
first callback implementation's scalar copy scored poorly; LDIR recovered most
of that modeled cost. Earlier run/source/logs remain preserved, not overwritten.

The final original AgonDev application validates the receiver comparator's bad/
good controls and compares every8192payloadbyte in each of four API/copy cases.
It records numbered logs and progress, retains the default test.bin filename,
and is not deployed to physical media in this tranche. Assembly wrapper source
and C register shims are examples for reuse, not a released standard library.

Results, identities, exact contracts and reproduction are in
experiments/uart0-completion/README.md and build/uart0-completion/run005/.
